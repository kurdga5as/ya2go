Политика конфиденциальности

Действует с 16 октября 2026 года. English version below.

Переезд — программа для macOS и Windows, которая копирует файлы с Яндекс.Диска пользователя в его Google Drive. Здесь описано, какие данные она использует и что с ними происходит.

Где работает программа

Программа работает только на компьютере пользователя. У Переезда нет своих серверов: файлы передаются напрямую с серверов Яндекса на серверы Google через интернет-соединение пользователя. Разработчик не получает файлы, пароли, ключи доступа или сведения о том, что и как переносится.

Какие доступы запрашиваются

  • Яндекс.Диск: чтение файлов и сведения о диске (cloud_api:disk.read, cloud_api:disk.info). Нужно, чтобы получить список файлов, их размер и содержимое. Изменять и удалять файлы на Яндекс.Диске программа не может.
  • Google Drive: доступ только к файлам, которые создала сама программа (https://www.googleapis.com/auth/drive.file). Нужно, чтобы загрузить файлы, проверить, какие уже перенесены, и сверить копии с оригиналами. Другие файлы в Google Drive программе не видны.

Что хранится и где

Ключи доступа (токены), которые выдают Яндекс и Google после входа, хранятся только на компьютере пользователя, в папке программы: на macOS ~/Library/Application Support/ya2gd, на Windows %AppData%\ya2gd. Там же хранится время, когда продолжить перенос после суточного лимита Google. Список непереносимых файлов сохраняется в файл, только если пользователь сам нажмёт «Сохранить список».

Программа не собирает статистику, не отправляет отчёты об ошибках, не показывает рекламу и никому не передаёт данные.

Как отозвать доступ и удалить данные

  • Кнопка «Выйти» в программе удаляет ключ доступа с компьютера.
  • Удаление папки программы удаляет все её данные.
  • Отозвать доступ на стороне сервисов можно в настройках аккаунта Google и в Яндекс ID.

Перенесённые файлы остаются в Google Drive пользователя и удаляются обычным способом.

Данные Google

Использование и передача информации, полученной через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use. Данные Google используются только для копирования файлов пользователя, которое он запустил сам, не передаются третьим лицам, не используются для рекламы и не читаются людьми.

Privacy policy (English)

Effective October 16, 2026.

Pereezd is a desktop application for macOS and Windows that copies files from the user's Yandex Disk to the user's Google Drive.

Where it runs

The application runs only on the user's computer. Pereezd has no servers of its own: files are transferred directly from Yandex servers to Google servers over the user's internet connection. The developer never receives the user's files, passwords, access tokens, or any information about what is being transferred.

Requested access

  • Yandex Disk: read files and disk information (cloud_api:disk.read, cloud_api:disk.info), to list files and download their contents. The application cannot modify or delete files on Yandex Disk.
  • Google Drive: access only to files created by the application (https://www.googleapis.com/auth/drive.file), to upload files, see which ones were already copied, and verify copies against the originals. Other files in the user's Google Drive are not visible to the application.

What is stored

OAuth tokens issued by Yandex and Google are stored only on the user's computer, in the application folder (~/Library/Application Support/ya2gd on macOS, %AppData%\ya2gd on Windows), together with the time to resume a transfer after Google's daily upload limit. The application collects no analytics, sends no crash reports, shows no ads, and shares no data with anyone.

Revoking access and deleting data

The "Выйти" (Sign out) button removes the token from the computer; deleting the application folder removes all of its data. Access can also be revoked in the Google Account permissions and in Yandex ID. Copied files remain in the user's Google Drive.

Google user data

Pereezd's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to perform the file copy that the user starts, is not transferred to third parties, is not used for advertising, and is not read by humans.
